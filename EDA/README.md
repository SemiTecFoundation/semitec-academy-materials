# EDA

Electronic design automation: the tools, flows and scripting behind chip design.

## Scope
- The design flow: simulation, synthesis, place & route, STA, sign-off
- Tcl and Python scripting for EDA tools
- Open-source flows: Verilator, Icarus, Yosys, OpenROAD / OpenLane
- File formats: Liberty, LEF / DEF, SDC, SDF, VCD
- Version control and continuous integration for hardware projects

_Hierarchy not final yet. Material folders (`lectures/`, `trainings/`, `labs/`, `projects/`, `videos/`, `materials/`) are added only at the last level, with `python3 tools/inventory.py --init <topic>`._

See [../README.md](../README.md) for the workflow.
