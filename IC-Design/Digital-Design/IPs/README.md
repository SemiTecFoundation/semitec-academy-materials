# IPs

Reusable design blocks and how to package them.

## Scope
- FIFOs (sync / async), memories, arbiters
- CRC, ECC (Hamming, SECDED)
- Parameterisation, documentation, IP-XACT / Vivado IP packaging
- Reuse and integration
