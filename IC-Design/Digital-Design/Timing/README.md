# Timing

Static timing analysis and timing closure.

## Scope
- Setup / hold, clock skew and jitter, slack
- Constraints (SDC / XDC): clocks, generated clocks, I/O delays, exceptions
- Clock domain crossing (CDC): synchronisers, FIFOs, handshakes
- Reading timing reports; timing closure techniques
