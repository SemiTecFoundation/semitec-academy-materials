# FPGA

Implementing designs on FPGAs (AMD AUP ZU3, Vivado / Vitis).

## Scope
- FPGA architecture: LUTs, flip-flops, BRAM, DSP, clocking resources
- Vivado flow: project / Tcl, synthesis, implementation, bitstream
- Constraints (XDC): pins, clocks, I/O standards
- Debugging: simulation, ILA, VIO
- Zynq: PS–PL, AXI, Vitis bare-metal applications
