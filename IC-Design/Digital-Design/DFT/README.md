# Design for Test (DFT)

Making chips testable after manufacturing.

## Scope
- Fault models (stuck-at, transition), fault coverage
- Scan chains, scan insertion, ATPG, compression
- IEEE 1149.1 (JTAG) boundary scan, IEEE 1687 (IJTAG)
- Test access and test time; DFT in the flow
