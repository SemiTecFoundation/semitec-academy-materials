# Analog Design

Transistor-level design of analog and mixed-signal blocks.

## Scope
- MOSFET operation and models, small-signal analysis
- Single-stage amplifiers, current mirrors, differential pairs
- Operational amplifiers: design, compensation, stability
- Comparators, voltage / current references (bandgap)
- Data converters (ADC / DAC) basics, PLL basics
- Layout, matching, parasitics; simulation (SPICE, corners, Monte Carlo)
