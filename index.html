SemiTec Academy Materials

Open learning materials and signed packages from SemiTec Foundation.

Use the Academy catalog

In SemiTec Academy, choose Catalog → Add a catalog link and paste:

https://semitecfoundation.github.io/semitec-academy-materials/catalog/catalog.json

The catalog currently offers BIST and MBIST, a signed six-training learning package.

Standalone browser trainings

These self-contained HTML files work in a browser without Academy:

  • Memory Fundamentals
  • BIST Foundations
  • Memories and Their Faults
  • March Tests
  • MBIST Architecture
  • Test Access: JTAG and IJTAG

Source and authoring

The editable material source is in this repository. Authors create and validate learning materials with the Academy Templates skills, then use the optional package skill when Academy delivery is needed.
